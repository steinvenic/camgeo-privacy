# CamGeo Privacy Policy

Public, bilingual privacy policy for CamGeo (`com.mnd.camgeo`).

Privacy policy URL:
https://steinvenic.github.io/camgeo-privacy/

The site contains no JavaScript, analytics, external fonts or tracking cookies.
Contact: steinvenior@gmail.com.

## Publish

In repository Settings → Pages, select **Deploy from a branch**, then
`main` and `/ (root)`. Save and wait for the Pages deployment to finish.
Only enter the Pages URL in Play Console after checking anonymous access.

## Maintain

Update `index.html` and push to `main`. Keep `.nojekyll` in the root.
This repository contains only the public privacy policy and hosting notes.
